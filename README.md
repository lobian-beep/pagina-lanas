# Lanas del Sur

Pagina web simple creada con HTML y CSS para practicar maquetado, estilos responsive y publicacion con GitHub Pages.

## Paginas

- Inicio: `index.html`
- Catalogo: `catalogo.html`
- Contacto: `contacto.html`

## Tecnologias

- HTML
- CSS

## Como ver el proyecto

Abrir `index.html` en el navegador o usar la extension Live Server de Visual Studio Code.
